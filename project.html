Featured Case Study ISDS 4125 Capstone

Supply Chain & Inventory Analytics Dashboard

A web-based decision support system designed to give operations managers real-time visibility into warehouse inventory levels, stockout risks, and supplier reorder timelines.

Role

Lead Analyst & Front-End Developer

Timeline

12 Weeks (Fall 2024)

Tech Stack

HTML5, CSS3, JavaScript, SQL

Category

Information Systems & Analytics

Read Case Study View GitHub Repository

The Challenge

Overcoming operational delays caused by disconnected tracking sheets.

Mid-sized distribution warehouses frequently rely on fragmented spreadsheet trackers updated manually at different shift intervals. This lack of centralized visibility caused recurring inventory stockouts for high-demand SKUs, inaccurate replenishment lead time estimations, and lost revenue during peak shipment periods.

The objective of this initiative was to engineer a centralized web dashboard backed by a normalized relational database schema that offers real-time inventory threshold alerts and decision-ready data metrics.

Key Features & Solutions

Functionality designed to streamline inventory decisions.

Real-Time Stock Alerts

Automated color-coded indicators that flag when item counts fall below safety stock limits, prioritizing replenishment orders based on average weekly burn rate.

Supplier Performance Metrics

Interactive tables tracking vendor lead times, fulfillment error rates, and shipment delays to assist procurement specialists in supplier negotiations.

Responsive Dashboard

Built using semantic HTML5 and clean CSS grid layouts, allowing warehouse floor supervisors to view dashboards on tablets and mobile devices seamlessly.

System Architecture & Design

Bridging business logic with database and front-end design.

Relational Database Modeling

Developed third-normal form (3NF) relational tables tracking Products, Warehouses, Suppliers, Inventory Transactions, and Purchase Orders. Designed primary and foreign key constraints to prevent data duplication and maintain relational integrity.

Analytical Query Optimization

Constructed complex SQL aggregation queries using joins, grouping, and window functions to compute inventory turnover ratios and identify slow-moving stock across specific seasonal windows.

Results & Key Outcomes

Measurable impacts observed during testing simulations.

40%

Reduction in Reorder Processing Time

Eliminated manual spreadsheet reconciliation by unifying reorder requests into a single verified interface.

100%

Stockout Alert Accuracy

Simulated test scenarios demonstrated immediate notification dispatch when SKU levels dropped below safety thresholds.
