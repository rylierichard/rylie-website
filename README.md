This repository contains my personal portfolio website, built for ISDS 4125 as an exercise in AI-assisted ('vibe') coding. The site includes a home page with my profile, skills, and experience, along with separate pages for my resume and a featured project. You can view the live site here: https://rylierichard.github.io/rylie-website/. When I asked the agent to make my site look good on mobile, it added something called a media query to my CSS file, which I'd never seen before. I asked it to explain what a media query does, and learned it's a rule that only applies when the screen is below a certain width, which is how one stylesheet can rearrange the layout for phones versus desktops.
